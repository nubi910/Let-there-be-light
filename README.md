# Let-there-be-light

사진 촬영용 라이팅 시뮬레이터. 브라우저(PC·모바일)에서 바로 열리는 단일 HTML 페이지예요.

## 기능

- **조명 3개(키·필·림):** 위치, 높이, 거리, 세기, 크기(맨 플래시 ~ 대형 옥타), 색(젤), 겨누는 방향
- **조작:** 위에서 본 배치도에서 끌기, 3D 화면에서 조명 탭 → 이동/회전/조절 메뉴
- **프리셋:** 렘브란트, 루프, 버터플라이, 스플릿, 클램쉘, 컬러 젤
- **키:필 비율:** 스톱 수 함께 표시
- **마네킹:** 흉상(얼굴 스캔) 또는 데생 인형(토르소·상반신 전체·허벅지까지·무릎 아래까지·전신)
  - 데생 인형은 얼굴 스캔 머리 + 관절 인형 몸. 얼굴 높이는 모든 종류에서 같음
  - 자세 프리셋(기본·콘트라포스토·허리에 손·손 모으기·한 팔 들기·걷기)과 관절별 회전
  - 3D 화면 직접 조작: 마네킹 메뉴 → 자세에서 팔다리를 탭해 관절을 고르고, 끌면 마디 끝이 손가락을 따라감(비틀기 모드 별도)
  - 얼굴 방향·고개 숙임·몸 방향
- **배경지:** 거리·각도·색 조절 (뒤쪽 조명을 가림)
- **그림자:** PCSS 소프트 섀도로 광원 크기에 따라 가까우면 선명, 멀수록 퍼짐
- **멈추면 다듬기:** 소프트박스 면 위 여러 지점에서 빛을 쏜 결과 64장을 평균(면광원 그림자, 안티에일리어싱, 심도)
- **카메라 모드:**
  - 렌즈 24~200mm(풀프레임 기준), 조리개, 얼굴 AF / 탭 초점(MF)
  - 화면비 틀, 격자(3분할·황금비·십자)
  - 렌즈 왜곡(광각 술통형 / 망원 실패형)과 보정 옵션
- **카메라 오브젝트:** 전체 보기에서 카메라를 탭해 이동·회전, 화각 범위 표시. "카메라" 버튼으로 그 시점에 들어감
- **카메라 위치 저장:** 여러 개 저장·불러오기·삭제, 초기 위치로 되돌리기 (3D 화면 바로 아래 줄)
- **링크 공유:** 조절 가능한 상태 전체를 압축해 주소 `#` 뒤에 담은 링크 생성 (`st`에 있는 값은 자동으로 포함)
- **다국어:** 한국어·English·日本語 (브라우저 언어로 자동 선택, 패널 위에서 변경)
- **사진 저장:** 카메라 구도(프레임 안)를 다듬기가 끝난 화면으로 고해상도 JPG 저장

## 사진 리라이팅 (베타)

위쪽 **사진** 버튼으로 찍어 둔 사진을 열면 3D 장면 안에서 다시 비춰 볼 수 있어요. 다시 누르면 사진 메뉴(바꾸기·지우기·카메라 맞추기·설정)가 열려요.

- AI가 사진 한 장에서 깊이를 추정해([Depth Anything V2 Small](https://huggingface.co/onnx-community/depth-anything-v2-small), Apache-2.0) 입체 부조를 만들고 마네킹 자리에 세워요
- 그래서 3D 조명(위치·거리·소프트박스 크기·그림자·다듬기·심도)과 배경지가 그대로 적용돼요
- 사진을 열면 깊이로 인물과 배경을 자동으로 나눠 배경을 잘라내고, 인물을 스탠드 위에 세워요 (배경 잘라내기로 조절)
- 원래 사진의 빛은 "원래 빛"만큼 남기고 그 위에 조명이 더해져요. 기존 그림자 펴기·입체감·사진 크기 조절
- "사진에 카메라 맞추기"로 사진이 프레임을 채우게 카메라를 정면에 둬요
- 브라우저 안에서만 돌고 사진은 기기 밖으로 나가지 않아요 (처음 한 번 모델 약 20~30MB 다운로드). 공유 링크에도 사진은 들어가지 않아요
- 한계: 입체는 추정값이라 정면 근처에서 볼 때 가장 자연스럽고, 이미 찍힌 강한 그림자는 완전히 지워지지 않아요

## 파일 구성

| 경로 | 설명 |
|---|---|
| `index.html` | 빌드 결과물. 이 파일 하나만 열면 동작해요 |
| `src/index.src.html` | 실제로 고치는 소스 |
| `src/i18n.js` | 다국어 사전 (키는 한국어 원문). 언어 추가는 여기에 |
| `assets/` | 얼굴 모델(`head.glb`)과 노멀맵 |
| `build.py` | 소스에 모델 데이터와 다국어 사전을 넣어 `index.html` 생성 |

## 빌드

```bash
python3 build.py
```

three.js r128은 CDN(cdnjs, jsdelivr)에서 불러와요.
