# Let-there-be-light

사진 촬영용 라이팅 시뮬레이터. 브라우저(PC·모바일)에서 바로 열리는 단일 HTML 페이지예요.

## 기능

- **조명 3개(키·필·림):** 위치, 높이, 거리, 세기, 크기(맨 플래시 ~ 대형 옥타), 색(젤), 겨누는 방향
- **조작:** 위에서 본 배치도에서 끌기, 3D 화면에서 조명 탭 → 이동/회전/조절 메뉴
- **프리셋:** 렘브란트, 루프, 버터플라이, 스플릿, 클램쉘, 컬러 젤
- **키:필 비율:** 스톱 수 함께 표시
- **마네킹:** 실제 얼굴 스캔 흉상, 좌우 회전·고개 숙임
- **배경지:** 거리·각도·색 조절 (뒤쪽 조명을 가림)
- **그림자:** PCSS 소프트 섀도로 광원 크기에 따라 가까우면 선명, 멀수록 퍼짐
- **멈추면 다듬기:** 소프트박스 면 위 여러 지점에서 빛을 쏜 결과 64장을 평균(면광원 그림자, 안티에일리어싱, 심도)
- **카메라 모드:**
  - 렌즈 24~200mm(풀프레임 기준), 조리개, 얼굴 AF / 탭 초점(MF)
  - 화면비 틀, 격자(3분할·황금비·십자)
  - 렌즈 왜곡(광각 술통형 / 망원 실패형)과 보정 옵션
- **카메라 오브젝트:** 전체 보기에서 카메라를 탭해 이동·회전, 화각 범위 표시. "카메라" 버튼으로 그 시점에 들어감
- **카메라 위치 저장:** 여러 개 저장·불러오기·삭제, 초기 위치로 되돌리기 (3D 화면 바로 아래 줄)

## 파일 구성

| 경로 | 설명 |
|---|---|
| `index.html` | 빌드 결과물. 이 파일 하나만 열면 동작해요 |
| `src/index.src.html` | 실제로 고치는 소스 |
| `assets/` | 얼굴 모델(`head.glb`)과 노멀맵 |
| `build.py` | 소스에 모델 데이터를 넣어 `index.html` 생성 |

## 빌드

```bash
python3 build.py
```

three.js r128은 CDN(cdnjs, jsdelivr)에서 불러와요.
